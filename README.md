# Finance Manager

Backend-сервис для управления личными финансами. Приложение позволяет пользователям вести несколько финансовых счетов, добавлять операции, распределять их по категориям и получать статистику по доходам и расходам.

Проект разработан на Java с использованием Spring Boot и PostgreSQL.

## Возможности

### Управление финансовыми счетами

* создание и удаление финансовых счетов;
* хранение текущего баланса каждого счёта;
* работа с несколькими счетами одного пользователя;
* автоматическое изменение баланса при добавлении, изменении или удалении транзакции.

### Управление транзакциями

Транзакция содержит:

* название;
* описание;
* сумму;
* дату;
* категорию;
* финансовый счёт.

Поддерживаются как доходы, так и расходы. Тип операции определяется знаком суммы.

При изменении или удалении транзакции баланс соответствующего счёта автоматически пересчитывается.

### Фильтрация транзакций

Для получения операций реализована система динамической фильтрации.

Доступна фильтрация:

* по пользователю;
* по конкретному финансовому счёту;
* по типу операции — доходы или расходы;
* по произвольному диапазону дат;
* по периоду — день, неделя или месяц.

Фильтры можно комбинировать между собой.

Для построения динамических условий используется `Spring Data JPA Specification`.

### Категории

Транзакции могут быть связаны с категориями, что позволяет группировать финансовые операции и анализировать структуру расходов и доходов.

### Финансовая статистика

Реализовано получение агрегированной статистики по категориям:

* общая сумма расходов по каждой категории;
* общая сумма доходов по каждой категории.

Агрегация выполняется непосредственно на стороне базы данных с использованием JPQL и `SUM`.

### Пагинация и сортировка

Получение списка транзакций поддерживает:

* постраничную выдачу;
* настройку размера страницы;
* сортировку по дате.

Это позволяет не загружать все операции пользователя одновременно и делает API пригодным для работы с большим количеством транзакций.

## Использованные технологии

### Backend

* **Java 21**
* **Spring Boot 4.1**
* **Spring Web** — создание REST API
* **Spring Data JPA** — работа с базой данных и репозиториями
* **Hibernate** — ORM
* **Spring Data JPA Specifications** — динамическая фильтрация
* **Jakarta Validation** — валидация входных данных
* **Lombok** — сокращение шаблонного кода

### Database

* **PostgreSQL**
* **JPQL** — запросы и агрегирование данных
* **HikariCP** — пул соединений с базой данных

### API

* REST API
* Swagger / OpenAPI для документирования API

## Архитектура

Проект построен с разделением приложения на несколько уровней:

* **Controller** — обработка HTTP-запросов;
* **Service** — бизнес-логика приложения;
* **Repository** — взаимодействие с базой данных;
* **Entity** — модели базы данных;
* **DTO** — объекты для передачи данных через API;
* **Mapper** — преобразование Entity и DTO;
* **Specification** — динамическое построение условий поиска.

Такое разделение позволяет отделить HTTP-слой от бизнес-логики и работы с базой данных и упрощает дальнейшее расширение приложения.

## Основные особенности реализации

В проекте используются несколько подходов, характерных для реальных backend-приложений:

* DTO вместо непосредственной передачи JPA Entity через API;
* разделение бизнес-логики и доступа к данным;
* динамические запросы с помощью `Specification`;
* пагинация через Spring Data `Pageable`;
* агрегирующие JPQL-запросы для получения статистики;
* автоматическое поддержание баланса счетов при изменении финансовых операций;
* транзакционность операций, изменяющих состояние счёта и транзакции;
* валидация входящих данных;
* REST API с документированием через OpenAPI.

## Статус проекта

Проект находится в разработке. Основная backend-часть реализована и постепенно расширяется новыми возможностями для анализа и управления личными финансами.
